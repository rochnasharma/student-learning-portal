## Introduction

Hey there! The **Student Learning Portal** is a lightweight web app built to give students one clean place for their notes, assignments, and coding practice, so they spend less time hunting for resources and more time actually learning.

## About the Project

**The Student Learning Portal** is *a hands-on, student-first project* that turns ~~stressful and chaotic studying~~ into a smooth, structured, and motivating experience.

![Educational image: Python programming logo](https://upload.wikimedia.org/wikipedia/commons/c/c3/Python-logo-notext.svg)

### Project Details

| Project Name            | Programming Language | Category           | Level        |

## Features

- Personalized dashboard showing courses and deadlines
- Organized notes and downloadable study material
- Daily streak and progress tracker
- Interactive coding challenges and mini quizzes
- Clean layout that works on phones, tablets, and laptops

### Technologies Used

1. Python (backend logic)
2. HTML5 (page structure)
3. CSS3 (styling and layout)
4. JavaScript (interactivity)
5. Git and GitHub (version control)
